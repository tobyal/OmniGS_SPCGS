# M1：Wan360 邻近视角与球面 SfM

本模块以真实训练 ERP 图像为条件调用官方 Wan360；从每条四方向视频的早期候选帧中选择一张能够几何定位的邻近图像，利用真实—生成匹配进行三角化。M2—M5 的损失、渲染和优化算法不变。

删除运动方向硬筛选后的 M1 对照实验见 [M1_NO_DIRECTION_GATE_20261023.md](M1_NO_DIRECTION_GATE_20261023.md)。此前的真实实验与短 SGI 验证见 [M1_RESULTS_20261023.md](M1_RESULTS_20261023.md)。当前推荐 `configs/m1_wan360_early.json`，候选帧 1–4；原始 `m1_wan360_test.json` 保留第 4/8/12/16/20 帧的对照配置。8/56 张配置采用早期候选，但尚未实际执行。

## 独立环境与真实权重

```bash
cd /mnt/sda/ubuntu/lkx/od/OmniGS_SPCGS_20261023
bash tools/setup_wan360.sh
```

脚本创建完全独立的 `.venv_wan360`，不继承或修改 OmniGS/CLIP/SAM2 的 Python 包。默认使用服务器现有 Python 3.10 启动 venv；可通过 `WAN360_BOOTSTRAP_PYTHON` 指向其他 Python >=3.10.1。安装官方要求的 Torch 2.6 / torchvision 0.21 和 MUGEN 依赖。

- [MUGEN 官方源码](https://github.com/AlayaLab/MUGEN)：固定提交 `628784299fd5c01394be9beeae052e63bc533ee5`。
- [Wan360 官方权重](https://huggingface.co/AlayaLab/Wan360)：固定版本 `914e60491baca94bf7c3346551bdb168b2445559`，包括完整 Wan360、Wan2.2 VAE、UMT5 与 tokenizer，约 24.7 GB。
- 权重和 Python 依赖记录在 `weights/Wan360/`，不提交 Git。下载完成后写入各文件 SHA256。
- 网络较慢时可用 `.venv/bin/python tools/download_wan360.py --http-workers 16 --direct-cdn --modelscope-base`；保存可恢复的分块，T5/VAE 从官方 Wan-AI ModelScope 下载后仍必须通过 Wan360 官方 LFS SHA256 校验。`--direct-cdn` 仅适用于 CDN 能直连的机器。可通过 `WAN360_TORCH_INDEX_URL` 和标准 `PIP_INDEX_URL` 选择可达的 Python 包索引。
- 已有验证过的 PyTorch/CUDA wheel 文件时，可以设置 `WAN360_WHEELHOUSE=/absolute/path/to/wheels`，先安装本地包，再检查并补齐官方依赖，避免重新下载大型运行库。
- `tools/wan360_worker.py` 调用官方 `WanVideoPipeline` 与 `inference.py` 的 `camera_trajectory`，使用工业静态场景提示词。未使用视频插值、原图平移或合成深度替代模型推理。

## 小规模执行

```bash
.venv/bin/python -m spcgs.pipeline --run m1_wan360_test \
  --config configs/m1_wan360_test.json --stage m1
```

初始配置只使用一张训练图，生成 forward/backward/left/right 四条 1024×512、49 帧、30 步视频，候选帧为 4/8/12/16/20（从 0 开始）。保存全部帧的无损 PNG，但仅将指定候选帧送入几何定位；修改候选索引可以复用视频。第 0 帧是输入条件帧，不能作为新观测。配置中的 `train_views=56` 是允许使用的真实训练几何支持集；`wan360.views` / `view_names` 单独控制昂贵的视频生成范围。

正常完成顺序：检查原始观测与坐标 → 真实 Wan360 推理 → 保存候选帧 → OpenMVG SIFT/RootSIFT → 特征匹配 → 生成相机定位与留出验证 → 每方向选择一张图 → 多视图三角化 → 去重及离群检查 → 增强点云。

## 坐标与几何依据

当前原始 `structure_filtered.json` 含三维点与 `id_feat`/像素观测，原先的数据副本只复制了 PLY 和空结构的相机 JSON。新模块读取原始观测，但只保留完整观测轨迹全部来自本次训练集、且能与当前初始 PLY 重合的点。默认路径：

```text
../datasets/iris_xphase1_work_2k/mvg/structure_filtered.json
../datasets/iris_xphase1_work_2k/mvg/*.feat, *.desc, image_describer.json
```

配置 `m1_geometry.structure` / `features` 可更改路径。只读原始特征和相机，不修改数据集。点坐标转换由现有点云重合程度验证，随后检查真实观测的球面重投影误差，不能凭空写入变换或注册成功标记。

OpenMVG 球面像素使用整数坐标：`lon=(u/W-0.5)*2π`、`lat=(v/H-0.5)*π`，相机方向为 `[cos(lat)sin(lon), sin(lat), cos(lat)cos(lon)]`。+Y 向下；这与本工程原生渲染像素中心的半像素约定有区别。Wan360 条件方向 +Y 向上，转换为先验方向时使用 `diag(1,-1,1)`，再由源相机旋转转入世界坐标。其位移单位没有米制标定，**不直接作为注册后的相机中心**。

生成帧与源训练图及其最近真实训练图匹配。原始观测提供 2D–3D 对应；在球面方向的虚拟前向半球上使用 PnP RANSAC 初始化，再对完整球面单位方向进行稳健位姿优化。虚拟投影仅用于 PnP 求解，不产生独立相机中心，也不把 ERP 像素直接当成针孔像素。

约四分之一的 2D–3D 对应留出、不参与拟合。注册还要求足够内点、空间覆盖、可测平移、合理旋转及留出误差改善。Wan360 的运动轨迹只用于生成邻近视角；`motion_direction_cosine` 仅作为实验分析指标记录，不参与筛选或评分。绝对相机位姿来自真实几何定位。

三角化使用固定的真实相机和已定位的生成相机的球面射线，检查真实—生成视差、正射线深度、球面重投影、真实观测数量、与原点云的距离、重复点及邻域密度。默认至少两个真实视角支持一个新点，可通过 `min_real_views` 调整。原有 3979 点全部保留，新增点使用真实图像颜色。

所有角误差统一换算为宽 2048 的球面像素单位，因此阈值不随生成视频分辨率任意改变。球面误差天然跨越 ERP 左右边界连续。

## 配置

`configs/m1_wan360_test.json` 提供可修改示例；所有默认值分别位于 `spcgs/wan360.py:settings` 与 `spcgs/m1_wan360.py:geometry_settings`。

| 配置 | 含义 |
|---|---|
| `wan360.python/repository/weights/cache` | 独立解释器、官方代码、权重及视频缓存路径 |
| `wan360.views/view_names/directions` | 生成源训练视角及运动方向 |
| `distance/width/height/num_frames/steps` | 未标定运动幅度与生成预算 |
| `prompt/negative_prompt/cfg_scale/sigma_shift` | 工业场景提示及采样参数 |
| `candidate_frames/reuse` | 候选帧索引及缓存复用 |
| `m1_geometry.neighbors/ratio/mutual` | 真实邻居、描述子匹配与互检 |
| `registration_error_px/min_*` | 注册、独立留出验证与平移/覆盖阈值 |
| `triangulation_error_px/min_parallax_deg/min_real_views` | 新点几何要求 |
| `duplicate_radius/max_distance_to_original/outlier_*` | 去重和离群检查，距离使用当前场景单位 |

缓存签名包含输入图像、模型版本、权重校验、生成配置、种子和推理包装程序。相同设置扩展视角数量时复用已有视频。特征缓存包含候选图、OpenMVG 二进制和描述子配置校验；匹配缓存校验两侧特征、算法代码、OpenCV 版本、种子与阈值。修改实验配置时使用新 run ID。

## 输出与失败

主目录：`runs/industrial_spcgs/<run_id>/01_sgi_sfm/`。

| 路径 | 内容 |
|---|---|
| `inputs.json/config.json/outputs.json/metrics.json` | 输入、配置、真实状态与计数 |
| `anchor_audit.json` | 原始观测过滤、坐标匹配和重投影审计 |
| `input_images/` | 所用真实训练全景图的只读来源链接，校验信息见生成任务 |
| `generation/` | 每条视频缓存的目录链接：MP4、条件轨迹、PNG 候选、配置与帧索引 |
| `wan360_provenance.json/wan360.log` | 官方版本、权重与实际推理日志 |
| `features/` | OpenMVG 输入相机定义、图像引用和描述子 |
| `matches/` | 匹配索引、比率、球面极线内点与误差 |
| `registration/` | 候选相机拟合结果、训练/留出对应及拒绝原因 |
| `candidate_scores.json/selected_views.json/invalid_views.json` | 全部候选评分、每视频选择与失败清单 |
| `selected/` | 选中图像的独立副本，可供下游读取 |
| `triangulation.json/observations.json/reconstruction.json` | 三角化候选、过滤决定、有效新点观测及固定真实相机重建 |
| `original.ply/new_points.ply/enhanced.ply/enhanced_points.f32` | 原始、新增和合并点云；F32 为 N×6 XYZRGB |
| `preview/report.md/error.log` | 图像、点云分布、匹配对比、报告和失败栈 |

没有可靠新增点时标记 `failed`，`outputs.json` 中 `points=null`，不会让 SGI 把原始点云误当增强点云。已生成视频、定位结果和统计保留。`skip/import/online` 原有模式保持兼容；`skip` 的原点云输入会明确标记。

