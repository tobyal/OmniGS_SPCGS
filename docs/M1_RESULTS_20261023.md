# M1 实测报告：Wan360 → 球面 SfM → 短预算 SGI

日期：2026-10-23。工程目录：`/mnt/sda/ubuntu/lkx/od/OmniGS_SPCGS_20261023`。

已用真实训练全景完成小规模闭环。推荐 `configs/m1_wan360_early.json`：复用四方向视频，仅检查第 1–4 帧，三个生成视角通过注册，新增 233 点，得到 4,212 点的增强 SfM。增强点云已由原生 SGI 正确加载并训练 100 步。

本次没有运行 8 张、56 张生成源的批量实验，也没有运行完整预算的 M2–M5 对比。相应配置和扩大命令已提供。下面的结论仅针对一张生成源全景、56 张真实训练图作为几何支持集的小规模实验。

## 输入与处理

- 生成源：训练图 `2023-05-11_10.18.46`，原图 ERP 2048×1024；不使用验证集或测试集生成数据。
- 原始 SfM：实际读取 3,979 点；原始 OpenMVG 观测、SIFT/RootSIFT 特征及相机保持只读。
- Wan360：官方 MUGEN 提交 `628784299fd5c01394be9beeae052e63bc533ee5`；权重版本 `914e60491baca94bf7c3346551bdb168b2445559`，三个大型权重均通过官方 SHA256 校验。
- 环境：独立 `.venv_wan360`，Torch 2.6.0+cu124、NumPy 2.2.6；官方依赖检查通过。OmniGS/CLIP/SAM2 原环境保持独立。
- 生成：forward/backward/left/right，1024×512，49 帧，30 步，seed=42，未标定运动幅度 0.8，工业静态场景提示词。
- 实际只生成 4 条视频，每条 49 帧，视频与轨迹逐帧对应；合计推理及保存约 376 秒。第二轮复用同样四条视频和无损帧，没有额外生成四条视频。
- 几何：原始训练观测提供 2D–3D 对应；球面定位、独立留出验证、真实—生成匹配、多射线三角化、去重及邻域筛选。真实相机保持固定，每个新增点至少由两个真实训练视角和一个已注册生成视角支持。

完整机器可读记录：[results/m1_20261023.json](results/m1_20261023.json)。实现及坐标说明：[M1_WAN360.md](M1_WAN360.md)。

## M2/SGI 接入验证

两轮均进行了原生 SGI 100 步短训练，使用各自的增强 F32 点云。

| 检查 | 第一轮 | 早期帧轮 |
|---|---:|---:|
| 初始高斯数 | 4,031 | 4,212 |
| 初始 XYZ 与增强点云逐点完全一致 | 通过 | 通过 |
| 训练步数 | 100 | 100 |
| 最终高斯数 | 13,991 | 14,183 |
| 损失及模型参数有限 | 通过 | 通过 |
| 最终点到初始云距离 P99 / 初始场景对角线 | 2.64% | 2.63% |

早期帧轮总损失首末记录为 5.154 → 3.451，RGB 损失为 0.2635 → 0.2466。不同迭代抽样图像可能不同，这些值用于运行检查，不构成重建质量对照实验。SGI 的新增和裁剪属于原有算法，最终高斯数不能作为 M1 新增 SfM 点数。

验证文件：各 run 的 `02_sgi_gaussians/m1_integration_check.json`。重复执行早期帧 M1 后，增强点文件 SHA256 保持 `77400a3de099bc5e3db0848249924ccb2f572850cc0e6bfb524fcfb013527939`，再次与 SGI 初始位置核对通过。

## 运行命令

推荐复现实测早期帧配置，使用新 run ID：

```bash
cd /mnt/sda/ubuntu/lkx/od/OmniGS_SPCGS_20261023
.venv/bin/python -m spcgs.pipeline --run m1_early_reproduce --config configs/m1_wan360_early.json --stage m1
.venv/bin/python -m spcgs.pipeline --run m1_early_reproduce --config configs/m1_wan360_early.json --stage features
.venv/bin/python -m spcgs.pipeline --run m1_early_reproduce --config configs/m1_wan360_early.json --stage sgi
.venv/bin/python tools/check_m1_sgi.py --run m1_early_reproduce
```

扩大配置已改用经过本次验证的候选索引 1–4；应先检查 8 张结果，再运行 56 张：

```bash
.venv/bin/python -m spcgs.pipeline --run m1_wan360_8 --config configs/m1_wan360_8.json --stage m1
.venv/bin/python -m spcgs.pipeline --run m1_wan360_56 --config configs/m1_wan360_56.json --stage m1
```

配置中的 `wan360.views` 控制生成源数量，`train_views=56` 控制真实几何支持集。相同模型、输入和生成参数会复用已有视频；改变候选索引不需要重新推理。

## 结果目录、可视化与限制

推荐结果位于：`runs/industrial_spcgs/m1_wan360_early/01_sgi_sfm/`，相对于上面的服务器工程目录。

- `original.ply`、`new_points.ply`、`enhanced.ply`、`enhanced_points.f32`：原始、新增、增强点云及 SGI 输入。
- `preview/*_real_generated.png`：上方真实全景、下方选中生成帧。
- `preview/*_matches.png`：真实—生成匹配，绿色为几何内点。
- `preview/point_distribution.png`：原始蓝点与新增红点的三轴投影。
- `preview/*_new_points.png`：四个固定训练视角下的新点位置；投影并不等于经过遮挡检验的可见性。
- `generation/`：四方向视频、全部 49 张无损帧、未标定条件轨迹及模型信息。
- `registration/`、`invalid_views.json`、`candidate_scores.json`：接受及拒绝原因。
- `matches/`、`triangulation.json`、`observations.json`、`reconstruction.json`：特征、轨迹、质量与固定真实相机的球面重建记录。

第一轮第 4–20 帧存在明显的细管线变形和模糊，绝大多数候选没有通过注册。较早帧更稳定，但 left 方向仍失败。当前结果支持“小规模闭环可运行、存在经过多视图筛选的新点”，不支持“所有生成视频都可信”或“已证明大规模质量提升”。没有把失败视角注册成功，也没有用深度反投影制造点云。

真实执行日志：`logs/m1_wan360_test.log`、`logs/m1_wan360_early.log`、`logs/m1_wan360_sgi_check.log`、`logs/m1_wan360_early_sgi_check.log`、`logs/m1_final_verification.log`。网络下载早期的超时保存在 `logs/wan360_*`；最终权重校验和环境安装成功。故意缺失权重的失败路径检查位于 `runs/industrial_spcgs/m1_missing_weights_regression_20261023/`，该检查不是生成实验。

另有两个球面数值单元检查通过。真实训练图的重定位诊断位置误差为 0.00843 场景单位、旋转误差为 0.206°，原图复制被拒绝；它与上述 Wan360 实验分开记录。Baseline 的 SHA256 仍为 `e3b44ce1f1e499cc39cad83a5d679e824804102e03367c2399ae9a9992e9334d`。
